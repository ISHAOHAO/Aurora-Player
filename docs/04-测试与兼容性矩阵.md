# Aurora Player — 测试与兼容性矩阵

**版本：** v1.0（基于 PRD 拆分）
**目标：** 把“全能播放”从口号变成可执行、可复现、可回归的测试体系。
**核心设施：** Media Compatibility Lab（固定硬件 + 固定素材 + 自动化脚本 + 真机 DLNA 矩阵）。

---

## 1. 测试素材库规范

### 1.1 素材命名（机器可解析）

```text
<container>__<vcodec>-<profile>-<bitdepth>__<resolution>__<fps>__<hdr>__<acodec>-<channels>__<sub>.<ext>

例: mkv__hevc-main10-10bit__2160p__23976__hdr10__truehd-71__ass.mkv
```

### 1.2 必测维度

| 维度 | 取值 |
| --- | --- |
| 容器 | mp4 mkv avi mov wmv ts m2ts mpg vob flv webm 3gp mxf mts |
| 视频编码 | h264 hevc av1 vp9 mpeg2 vc1 xvid theora prores dnxhd ffv1 |
| 位深 | 8 / 10 / 12 |
| 分辨率 | 480p 576p 720p 1080p 1440p 2160p（发烧: 4320p/8K+） |
| 帧率 | 23.976 24 25 29.97 30 50 59.94 60 100 120 240 |
| HDR | sdr hdr10 hdr10plus hlg（色彩: bt709 bt2020 p3） |
| 音频 | aac mp3 opus flac ac3 eac3 dts dtshd truehd pcm |
| 声道 | 2.0 / 5.1 / 7.1 / 7.1.4 |
| 字幕 | srt ass ssa vtt sup(pgs) idx+sub（编码: utf8 gbk big5） |

### 1.3 特殊素材

- 高动态动漫场景（线条/色块 banding 检测）
- 暗场电影片段（black crush 检测）
- 高码率片段（>80 Mbps，解码压力）
- 隔行素材（TFF/BFF/混合 telecine）
- 损坏/畸变文件（截断、错索引、异常头 —— 不得崩溃，须优雅报错）
- 恶意构造样本（XXE XML、路径穿越字幕名、超大 ASS 特效 —— 安全回归用，隔离环境）

## 3. 画质评价（不只看“能不能播”）

| 项目 | 方法 | 基准 |
| --- | --- | --- |
| Banding | 渐变测试图 + 暗场目测 | 与 madVR/mpv 对比不劣化 |
| Ringing/缩放伪影 | 1080p→4K 放大对比 | 不引入可见振铃 |
| Highlight clipping | HDR 高光素材 | tone mapping 后保留层次 |
| Black crush | 暗场素材 | 不丢暗部细节 |
| Color shift | 标准色卡视频 | ΔE 可感知范围内无偏移 |
| Chroma | 4:2:0 测试图 | 无色边 |
| 字幕亮度 | HDR 片中 ASS 白字 | 不刺眼、不发灰 |
| 去隔行 | 运动横线/斜线素材 | 无梳齿 |

**A/B 对比对象：** MPC-HC+madVR、mpv、PotPlayer、VLC、Windows Media Player。同源素材、同显示器、双盲记录。

## 9. 自动化与报告

- **CI 门禁：** 每次合并跑冒烟集（30 条核心用例，<20 min）。
- **Nightly：** 全量本地矩阵（约 400 组合），自动出 HTML 报告（通过率/回归 diff/失败日志/录屏链接）。
- **每周：** DLNA 真机矩阵 + 24h 稳定性。
- **发布前（RC）：** 全矩阵 + A/B 画质对比 + 安全回归，全绿方可签字发布。
- 每条失败自动附带：素材ID、环境指纹（GPU/驱动/OS/显示器）、引擎日志、dlna.log、录屏。
