## 2. 第一设计原则（继承并形式化）

```
Video
  ↓
Atmosphere
  ↓
Ambient Light / Particles
  ↓
Player UI
```

**强制手段（不是自觉）：** 氛围层一律 `mix-blend-mode: screen` + 亮度/饱和度钳制 + `bgOpacity` 上限。
视频亮处 blend 无效 → 视频保持主导；只有暗处被加光。播放页透明窗下氛围层不产生不透明背景。

## 3. 架构

```
app/renderer/src/visual/
├─ types.ts            VisualTheme / ResolvedVisualTheme / VisualParams / PlaybackState
├─ registry.ts         VisualThemeRegistry —— 内置 6 主题 + list/get/cloneBuiltin/register
├─ resolver.ts         ThemeResolver.resolve(theme, { coverPalette, state }) → ResolvedVisualTheme + cssVars
├─ store.ts            VisualStore —— activeTheme/preset/overrides、setParam→resolve→写变量、订阅
├─ persist.ts          UserPresetStore —— save/saveAs/rename/duplicate/delete/reset/export/import
├─ engines/
│  ├─ BackgroundEngine.ts    scene 背景（solid/gradient/cover/cover-derived，opacity 钳制）
│  ├─ AtmosphereEngine.ts    grain/vignette/bloom 层（DOM+CSS，screen 混合）
│  ├─ LightingEngine.ts      环境光池（cover 主色，亮度/饱和钳制，缓存）
│  ├─ ParticleEngine.ts      canvas 粒子（对象池，rAF，reduced-motion 停）
│  └─ MotionEngine.ts        camera/kenBurns/parallax（transform/opacity，门控）
├─ PlayerAtmosphere.ts       播放态门控子集（仅 player 路由启用全预算）
├─ VisualConsole.tsx         右缘贴边控制台
├─ VisualProvider.tsx        一次性 mount + 订阅 + 路由/播放态驱动
└─ useVisual.ts              hooks
```

**深模块纪律：** 业务组件只碰 `VisualProvider` / `useVisual`。删除整个 `visual/` 复杂度不回流入业务层。
**主题即数据：** 新增主题 = `registry` 加一个 JSON 对象，业务组件零改动。

## 4. VisualTheme schema（定稿）

```ts
interface VisualTheme {
  id: string; name: string; description?: string;
  source: 'builtin' | 'user'; version: 1;

  scene: {
    mode: 'solid' | 'gradient' | 'cover' | 'none';
    bgOpacity: number;                       // 0..1，播放页 ≤ 0.9
    gradient?: { start: string; middle?: string; end: string; angle: number };
    cover: { follow: boolean; locked: boolean; auto: boolean };   // Auto/Manual/Off + Lock
  };

  lighting: { enabled: boolean; intensity: number; blur: number; spread: number; saturation: number; temperature: number };
  particles: { enabled: boolean; density: number; speed: number; size: number; opacity: number; depth: number; reaction: number };
  motion: { enabled: boolean; camera: number; parallax: number; kenBurns: number; transitionSpeed: number };
  atmosphere: { grain: number; bloom: number; vignette: number; aberration: number };

  ui: { opacity: number; glass: number; blur: number; border: number; radius: number; density: 'compact'|'comfortable'|'spacious'; accent: string };
  player: { controlOpacity: number; autoHide: number; metadata: 'minimal'|'normal'|'technical'; defaultPresentation: 'normal'|'immersive' };

  advanced?: { particleDepth?: number; lightFalloff?: number; bloomSamples?: number;
               motionCurve?: 'linear'|'ease'|'cinematic'; extremeOpacity?: boolean; performance?: 'balanced'|'high'|'eco' };
}
```

## 5. 主题应用流程

```
store.apply(themeId)
  coverPalette = LightingEngine.getCoverPalette(当前封面)   // Auto 时；播放页用 getThumb 帧，缓存+节流
  resolved = resolver.resolve(theme, { coverPalette, playbackState })
  写 cssVars → <style data-visual>（覆盖 base 令牌）
  engines.start(resolved) → scene/光照/粒子/运动
  data-vtheme / data-immersive 更新

store.setParam(path, v)   // 实时调参
  重新 resolve + 重写对应变量 / 直推引擎（粒子改 canvas 参数）
  连续值不触发 React 重渲染
```

**token 映射（resolver 内）**：schema → `--vs-*` 系列（bg/surface/line/text/accent/radius/glass/chrome-opacity/density/player-opacity）+ `--ov-*`/`--cv-*`（播放器/封面），并产出 `data-vtheme`。

## 7. 状态分级

```
Browse/Library → LOW：gradient + 少量粒子 + grain（无 bloom/vignette/运动）
Settings       → STATIC：仅 grain + 最低 ambient
Playback       → MEDIUM：全引擎，按主题预算
Immersive      → FULL：UI 最小化、metadata 延迟隐藏、灯光/粒子/相机增强
```

## 8. 持久化

- `userData/visual.json`：`{ version, activeThemeId, activePresetId, presets: VisualTheme[] }`
- 官方主题 = registry 常量，永不落盘；修改官方主题 → 自动 clone 为 `source:'user'` 的「Custom Copy」
- 首次启动迁移：`settings.visualMode` → 新主题 id（向后兼容）
- 重启后：当前主题 + 当前 preset + 用户参数恢复

## 9. 性能（硬约束）

- 粒子：单 canvas + 对象池；路由离开 player / idle 隐藏 / reduced-motion → 停帧；DPR ≤1.5；密度按面积封顶
- 氛围层：仅 transform/opacity/blend，合成层，零 layout
- 连续值：store→style/canvas 直写，不触发 React
- cover 取色：32×32 离屏降采样 + 按文件缓存；播放页 `getThumb()` 加缓存/节流
- 不引入 WebGL 框架；Advanced 先 CSS/canvas 近似

## 11. Phase 4 设计修正（2026-08-16）

### 修正 1 — Video First 是运行时强制约束，不是约定

`scene.bgOpacity` 保留在 schema，但 Resolver 按 playback state 施加**硬上限**，Custom/Advanced 无法绕过：

```ts
const STATE_BUDGET = {
  browse:   { bgOpacityMax: 0.20 },   // Home / Library / Search
  settings: { bgOpacityMax: 0.12 },
  playback: { bgOpacityMax: 0.18 },   // Normal
  immersive:{ bgOpacityMax: 0.28 },   // Immersive
};
effectiveOpacity = Math.min(theme.scene.bgOpacity, budget.bgOpacityMax);
```

播放页透明窗下：scene/light/bloom 层一律 `mix-blend-mode: screen`，只加光不遮画面。

### 修正 2 — 三种视觉强度严格独立

| 强度 | 控制 | 对应输出 |
|---|---|---|
| **Scene Opacity** | background / ambient / cover-derived light | `scene.opacity`、`light.opacity` |
| **Atmosphere Intensity** | grain / bloom / vignette / particles / motion | 各自 opacity 与引擎参数 |
| **UI Opacity** | player controls / metadata / glass panels / chrome / buttons | `--vs-chrome-opacity`、`--vs-player-opacity`、`--vs-metadata-opacity`、glass alpha |

`UI opacity ↓` 不得连带 `Lighting ↓`，反之亦然。三组在 Resolver 中分别解析、互不写入。

### 修正 3 — IPC 是 persistence boundary，不是 rendering boundary

实时调参路径：

```text
VisualConsole → VisualStore → Resolver → CSS variables / Canvas engine
```

**不允许**每个 slider tick 走 `renderer → IPC → main → fs.writeFile`。持久化仅在：

- debounce 300–800ms 后
- Save / Save As / Rename / Preset 切换
- 应用退出前必要时

### 修正 4 — Theme 与 Playback Presentation 解耦

```text
Theme（长什么样）        Playback Presentation（有多沉浸）
├─ Cinema                 ├─ Normal
├─ Aurora                 └─ Immersive
├─ Noir / OLED / Glass
├─ Immersive
└─ User presets
```

schema 中 `player.immersive: boolean` **作废**，改为：

```ts
player.defaultPresentation: 'normal' | 'immersive'   // 仅主题的默认倾向，非唯一来源
```

运行时最终状态由 `activeTheme + playbackPresentation + route + playbackState + fullscreen + UI idle` 共同决定。允许任意组合（Cinema+Immersive、Aurora+Immersive、Custom+Immersive）。

**关键**：UI idle（控制层隐藏）≠ Immersive。Immersive 必须由 手动切换（`V`）/ 用户偏好 / 明确的全屏策略 进入；用户退出后不会因再次 idle 自动重入。

### 修正 5 — Cover Palette 与 Frame Palette 区分

```ts
type PaletteSource =
  | { type: 'cover';  fileId: string }       // poster / cover / thumbnail
  | { type: 'frame';  playbackId: string }   // 播放中：现有 getThumb() 代表帧
  | { type: 'manual'; colors: string[] };
```

- **Home / Library**：优先 Cover Palette（本地 poster 32×32 降采样，按 file 缓存）
- **Player**：优先 Frame Palette —— 复用现有 `getThumb()`，**不加新 IPC**；`≤1 次/2s` 节流 + 按 media 缓存 + debounce + 色彩平滑/hysteresis，避免画面轻微变化导致环境光闪动。禁止逐帧取色。
- 换片 → 提取代表帧 → 计算 palette → LightingEngine 平滑过渡（不跳变）。

## 14. Phase 4.y 修正（2026-08-16，主题差异化 + Settings 同步）

### 修正 A — 6 主题成为 6 套设计语言（Theme Differentiation）
- 每主题新增 **ThemeSignature**（layout/typography/surface/shape/density/motion/atmosphere 语义）。
- Resolver 将 signature 翻译为具体差异：**Typography**（Noir=Georgia 衬线 display，其余无衬线；display 标题 + mono 元数据/时间码）、**Surface**（matte/paper/flat=无阴影、glass=浮层、luminous/atmospheric=光晕）、**Shape**（radius 2/4/8/14/18）、**Density**（compact 0.82–spacious 1.28，海报/磁贴/间距缩放）。
- **Layout 语言**（CSS 按 `body[data-vtheme]`）：Noir=海报轨转纵向索引 + 隐藏 shortcuts 磁贴 + 编号章节（CSS counter 001/002/003）+ 纸面；OLED=紧凑网格无阴影；Glass=磁贴/封面玻璃材质（仅必要层）；Aurora=更宽松 + 发光表面。
- **OLED Light ≠ OLED Dark**：移除 darkOnly。Dark=纯黑影院（`#000`）；Light=**亮白参考模式**（`#FBFBFB`、纯白表面、黑字、无氛围光、flat），两者亮度差 >230。

### 修正 B — Settings 主题选中状态同步
- 根因：Settings.tsx 未订阅 VisualStore，点击 `store.apply()` 后不重渲染 → 高亮停留旧主题。
- 修复：Settings 改用 `useActiveTheme()`（`useSyncExternalStore`）读取 `activeThemeId`，以 **VisualStore 为唯一 runtime source**；无本地第二份状态。点击 → store.apply → emit → React 重渲染 → 选中按钮同步。内置主题 id 与用户 preset id 不混淆。

## 15. Phase 5 真实播放 QA（2026-08-16）

**环境**：真实 Electron + mpv 0.41 + 透明窗 + 真实 IPC；CDP 驱动真实渲染层 + 真实窗口截图 + 像素采样。

**关键架构发现与修复**：
- **透明窗架构下 DOM blend 看不到 mpv 视频**（mpv 是原生子窗口，backdrop=透明 body）——`mix-blend-mode: screen` 对视频无效，scene 层实际是盖在视频上的真实半透明暗色层，曾使白场视频中心从 254 降到 192（24% 洗暗）。修复：**播放页 scene 透明度 = 预算 × 0.2（低语级 ≤0.056）**，白场中心恢复 240（0.94）。
- **中心光斑抬黑场**：55%/45% 的环境光斑让黑场中心被染色；修复：光斑全部移到边角（86/5、4/94、88/92），黑场中心实测 0,0,0。
- 附带 tuning：light 不透明度 1.15→1.05、grain 上限 0.12→0.09、粒子中心避让增强。

**验收数据**（真实播放）：
- 六主题黑场中心 lum ≤0.067（OLED 0.000，均为极轻 grain 底噪，无可见抬黑）；白场中心 0.94（视频主导）
- Normal 与 Immersive 播放：**drop-frame-count Δ=0**，vf-fps 稳定 30.0，mpv 内存 ~116MB——视觉系统不影响播放稳定性
- HDR（hdr-pq-test.mp4）真实播放通过，硬解启用
- 窗口：全屏/最大化/最小化后视觉系统存活、无 console error；screen-probe 中心亮度 127.4（透明窗视频可见）
- Immersive 手动切换 / UI idle ≠ Immersive / Console backdrop+让位 / Appearance(Light/Dark/System) / OLED Light(亮白参考)≠Dark(纯黑) / Frame palette 平滑+换片更新 / Custom 编辑→SaveAs→重启→全参数恢复、官方主题未被覆盖 —— 全部通过

## 16. P2 修复：播放中换片偶发失效（2026-08-16，main.js）

**根因**：`cleanupPlayback()` 对旧 mpv 调用异步 `kill()` 后立即 `spawnMpv` 新 mpv 并连接**同一条**命名管道 `\\.\pipe\aurora-mpv`。竞态：新 `net.connect` 可能连到**正在退出的旧 mpv 管道**，旧进程退出后该连接静默断开且不触发重试 → 新会话无状态推送（视频实际在播，但渲染层看到 stale/空标题）。偶发与否取决于 kill 完成时机。

**修复**（`app/main/main.js`）：
- 拆分 `resetSession()`（同步复位）/ `killMpv()`（异步，等待当前 + 任何正在退出的 mpv **完全退出**后再返回）/ `cleanupPlayback()`。
- `startPlayback` 变为 async，**先等旧 mpv 完全退出（释放命名管道）再 spawn 新 mpv**。
- `stopPlayback` 同步复位 + 后台杀进程（不阻塞返回首页）；下一次 start 会等它退完。
- `connectPipe` 捕获每次连接的 socket，`error`/`close` 均触发重连（受 `pipe===thisPipe && mpvProc && !quitting` 保护），杜绝连到垂死管道后静默断连。

**验证**：复现 3/6 失败 → 修复后 **6/6 × 3 次全通过**（每次 1s）；回归 `visual-test 77/77 · hdr 23/23 · dmc 21/21 · security 12/12 · pipe OK · qa-matrix 44/44` 全绿。

## 17. Aqua 主题（第 7 内置，默认）

**来源：** 仿照 DSH-Transparent-UI-Plugin（Aqua 毛玻璃主题）。完整设计见 `docs/superpowers/specs/2026-08-17-aqua-ui-design.md`。

**特性：** 深海军蓝/冷白双外观 · 悬浮毛玻璃卡片（20/14/8 圆角体系）· WebGL 流体背景（色相/深度可调）+ 自定义壁纸 · 顶/底边缘雾化 · 光标聚光 + hover 3D 按压 · 粒子鲸鱼 + 鱼/气泡/浮游海洋生物。

**架构：** Aqua 为第 7 内置主题（`registry.ts`），`theme.aqua` 可选段承载专属参数；新增 4 个运行时单元（FluidEngine / CrittersEngine / SpotlightEngine / EdgeFadeLayer），controller 统一编排。播放页受透明窗约束：流体 mask 到 letterbox 边缘带，中心露出 mpv；视频充满窗口时流体隐藏。

**默认值：** `store.ts` 默认 `activeThemeId='aqua'`；新装/迁移无映射落 aqua；已有 `visual.json` 用户保持当前主题。编辑官方 Aqua 自动 clone 为 Custom Copy。
