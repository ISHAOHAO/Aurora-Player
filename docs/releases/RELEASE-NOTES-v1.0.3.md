# Aurora Player v1.0.3

构建日期：2026-09-21

## 更新内容

- 统一首页、设置页与系统外观的主题状态，修复“跟随系统”与手动明暗模式不同步。
- 网络媒体与 NAS 弹窗增加输入校验、加载反馈、错误提示、焦点隔离和键盘操作。
- 播放进度条升级为可拖拽、可键盘控制的标准滑块，并增加媒体打开与慢加载状态。
- 设置页开关、分段选项和滑块补充无障碍语义，连续滑动设置采用防抖保存。
- 清空播放记录、清空媒体库和移除媒体文件夹增加二次确认。
- 提升次要文字对比度、开关点击区域、滚动条可见性与键盘焦点反馈。
- 清理 Vite 配置格式与视觉控制台动态导入构建警告。

## 安装与迁移

Windows 10 / 11 x64，推荐运行 `AuroraPlayer-Setup-1.0.3.exe`，也提供 MSI。
安装包包含播放运行时，可覆盖安装 1.0.2；用户设置和媒体库数据沿用现有用户数据目录。
本地生成安装包不会上传发行附件，也不会修改生产 `update/latest-split.json`。
