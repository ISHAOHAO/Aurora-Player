# Aurora Player v1.0.1

日期：2026-09-03  
平台：Windows x64，主要验证环境为 Windows 11。  
状态：已准备本地安装包，尚未上传公开发行。

## 版本说明

v1.0.1 汇总 v1.0.0 之后的项目审查修复、播放观感优化、DLNA 换集修复和音量条改进。本次以稳定性修复和现有功能优化为主，采用补丁版本递增；应用内“关于”、安装程序与安装包名称统一为 **1.0.1**。

此前标为 1.0.0 的审查候选和播放修复候选已归档。请使用本次重新构建的安装包，不要依靠旧包改名判断版本。

## 本次重点

### 视频画面优先

- 播放页停止并移除氛围背景、环境光、粒子、动态壁纸和聚光装饰，不再透过视频干扰观看。
- 暂停、换集和全屏沿用同一策略；回到首页或设置后恢复主题效果。
- 控制条保留必要的交互动画；不再为播放页的装饰效果持续提取视频配色。

### 投屏换集保持状态

- 新一集保留全屏、音量和静音状态，修复换集后音量恢复默认值的问题。
- 新播放进程从启动时就使用保留音量，避免先以默认音量播放再调低。
- 支持投屏端先停止再加载下一集的流程；远程停止媒体会保留播放窗口，本地主动返回首页仍退出全屏。
- 修复引擎连接期间调音丢失、旧状态回报覆盖新音量等时序问题。

### 音量条更易操作

- 支持连续拖动、点击、方向键微调和 Home/End，扩大可操作区域。
- 即时显示音量百分比，拖动紧跟指针，悬停与松手反馈更柔和。
- 静音保留音量位置；调高音量自动取消静音。
- 保留投屏控制锁定，并遵循系统减少动画设置。

## 稳定性与数据修复

- **播放会话：** 连续打开以最后一次请求为准，旧进程退出和迟到回调不再破坏新会话；引擎通信增加超时与断连清理，异常退出最多自动恢复两次。
- **续播：** 打开入口统一处理记忆设置、明确指定的起点和片尾位置；刷新最近播放信息不再覆盖已保存的进度。
- **媒体库：** 扫描及批量写入移到后台，清空操作真正落盘；事务失败回滚；离线或未完成扫描保留原记录并显示提示。封面抽帧只更新对应项目。
- **HDR 与性能：** 恢复默认参数和切换模式时完整重置受控属性；按新增丢帧判断性能压力，避免历史累计值误触发降档。
- **更新体验：** 修正更新源配置与“有新版本”的判断；关于页恢复当前下载状态；开发环境明确提示更新不可用。
- **安装关联：** 安装器只将 Aurora 添加到视频文件“打开方式”，默认播放器仍由用户选择；卸载保留其他程序的关联信息。
- **构建一致性：** 固定发布工具依赖，校验 mpv 运行时；类型检查和回归检查成为打包前置步骤，发布文件按版本分目录保存。

## 投屏兼容性变化

DLNA 入口加强局域网地址、DNS、重定向与事件回调校验，修复订阅续期及资源清理，并限制请求和通知预算。

**当前 DLNA 投屏仅支持受控的直接媒体文件，不支持 HLS/DASH 清单或媒体外部引用。** 支持的解复用格式包括 MP4/MOV、MKV/WebM、AVI、MPEG/TS、MP3、FLAC、WAV、AAC、ASF/WMV 和 FLV。使用清单型地址或公网转发链路的投屏端可能无法播放；请使用可达的局域网直连媒体地址。这一限制仅描述 DLNA 入口，不应理解为已承诺所有本地或网络格式均可播放。

## 安装与升级

| 文件 | 用途 |
| --- | --- |
| `AuroraPlayer-Setup-1.0.1.exe` | 日常安装和升级，NSIS 渠道支持应用内更新 |
| `AuroraPlayer-Setup-1.0.1.msi` | 手动安装或部署；不作为应用内自动更新载体 |
| `AuroraPlayer-Setup-1.0.1.exe.blockmap` | EXE 差量更新辅助文件，无需单独运行 |
| `latest.yml` | 本地构建更新元数据，包含版本、文件大小及 SHA-512 |
| `SHA256SUMS.txt` | 上述文件与本说明的 SHA-256 校验值 |

关闭正在运行的 Aurora 后，使用与原安装渠道一致的新包安装。安装时可选择目录及是否加入视频“打开方式”。常规升级沿用已有用户数据；涉及重要媒体库或设置时，可先保留用户数据备份。默认音量设置保留，当前应用运行期间的音量会跨集继承。

自动更新要在附件上传、生产更新清单发布后才会发现此版本。本地生成安装包不代表已向所有用户推送更新。文件散列用于验证完整性，不能替代发布者签名。
