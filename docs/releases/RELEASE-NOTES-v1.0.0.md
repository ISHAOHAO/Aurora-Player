# Aurora Player v1.0.0

> Win10/Win11 沉浸式视频播放器 —— 本地 / 网络 / DLNA 全能播放，HDR 画质决策链，媒体中心。

Aurora Player 是一款面向 Windows 11 的桌面视频播放器，以「电影镜头、粒子视觉与舞台」为设计语言，在 mpv 解码内核之上构建了完整的沉浸式体验：自绘控制层、HDR 画质决策、DLNA 投屏（MediaRenderer）、本地媒体库海报墙与 NAS/SMB 在线浏览。

---

## ✨ 特性总览

### 🎬 播放引擎
- **mpv 0.41 内核**：覆盖 MP4 / MKV / AVI / MOV / TS / WebM 等主流容器
- **硬件解码自动协商**：D3D11VA / DXVA2 / NVDEC，失败自动降级软件解码，不报「无法播放」
- **HDR 画质决策链**：HDR10 / HLG 自动直通或色调映射，7 种 Tone Mapping 算法可选，支持目标峰值 / 对比度恢复 / 饱和度实时调参
- **独立子进程隔离**：mpv 崩溃自动恢复；命名管道 JSON IPC 双向控制，UI 与引擎完全解耦

### 🎨 沉浸式 UI
- 「电影镜头、粒子视觉与舞台」设计语言，明暗双主题
- 环境光舞台（柔光场 + 粒子尘光）、三级 Glass 浮层、自绘控制层
- 进度条悬停显示真实帧缩略图 + 章节标记 + 时间气泡

### 📡 DLNA 投屏
- 完整实现 DLNA MediaRenderer（DMR）：手机 / NAS / 电视可发现并推送播放
- 状态同步、控制权仲裁、后台待机接收投屏

### 🗂️ 媒体库
- 纯本地刮削海报墙（文件名 / nfo / 同目录封面解析，**无在线依赖**）
- 剧集识别、无封面自动抽帧；SQLite 持久化
- NAS / SMB UNC 路径在线浏览，直连点播无需入库

### ⚙️ 工程化
- 系统托盘待机、续播记忆、防火墙自检
- **自动更新**：Gitee 源，启动后台检查 → 自动下载 → 退出时静默安装（差量更新，只下载变更字节）
- 安装器支持：自选安装目录 + 文件关联勾选（NSIS）/ 企业分发（MSI）

## 📦 安装包

| 文件 | 说明 |
| --- | --- |
| `AuroraPlayer-Setup-1.0.0.exe` | NSIS 安装包（**推荐**，支持自动更新），安装时可勾选文件关联、自选安装目录 |
| `AuroraPlayer-Setup-1.0.0.msi` | MSI 安装包（企业分发 / 组策略批量部署场景） |

## 🚀 安装说明

1. 下载 `AuroraPlayer-Setup-1.0.0.exe` 并双击运行
2. 安装向导中可选择**安装目录**，并可勾选是否将 `.mp4 .mkv .avi .mov .flv .wmv .webm .ts .m2ts .mpeg .mpg` 关联到 Aurora Player
3. 默认 per-user 安装（`%LOCALAPPDATA%`），**无需管理员权限**、不触发 UAC
4. 卸载时仅清理本程序写入的文件关联，不影响其他播放器

## 🔄 自动更新

- 版本真相源：Gitee 仓库 `update/latest.yml`（raw 托管，地址永不变）
- 安装包本体：Gitee 发行版附件（绝对直链，国内访问稳定）
- 已安装用户**启动应用后自动检查**，发现新版自动后台下载，退出应用时静默安装；也可在「设置 → 关于」手动检查
- 下载完整性由 sha512 校验，防止篡改
