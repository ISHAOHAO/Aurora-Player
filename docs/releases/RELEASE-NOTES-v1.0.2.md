# Aurora Player v1.0.2

发布日期：2026-09-06

## 更新内容

- 新增 Gitee 分片更新：每片不超过 80MiB，下载后自动合并安装包。
- 每个分片及完整 EXE 均进行 SHA-512 校验，下载失败最多尝试三次，重新检查可复用已校验分片。
- 下载完成后，用户点击“退出并打开安装向导”安装更新；启动失败或安装包校验失败时保留播放器运行。
- 使用独立的 latest-split.json 更新清单；发布工具生成 EXE/MSI 分片，并提供远程下载验证命令。
- README 增加 Windows 安装包下载渠道，具体下载地址由发布者填写。

## 安装与迁移

Windows 10 / 11 x64，推荐运行 AuroraPlayer-Setup-1.0.2.exe，也提供 MSI。
1.0.1 及更早客户端不支持分片更新，需要手动安装一次本版。
首次安装请使用完整安装包，不能直接运行 .partNNN 文件。
新更新源须在附件上传并验证后发布；本地打包不会上传 Gitee 或覆盖生产清单。

## 验证范围

打包前运行回归测试、HDR 决策测试、视觉逻辑测试、TypeScript 检查、前端构建与运行时检查。
本地分片合并与哈希校验不代表 Gitee 匿名下载、大陆网络速度或实际 Windows 安装升级已通过验收。
本版仍为未签名安装包，保留 SHA256SUMS.txt 供核对文件完整性。
