# Aurora Player — UI/UX 设计规范

**版本：** v1.3（基于 PRD 拆分；v1.1 去"AI 味"；v1.2 双主题+环境光；v1.3 沉浸式视觉定位+浅色全覆盖）
**适用范围：** Aurora Player 全部界面、组件、动效与交互
**设计基线：** Windows 11 Fluent + 沉浸式影音视觉语言（参考 Mineradio 的设计哲学，不复用其代码与资产）

---

## 1. 设计原则

| 原则 | 说明 |
| --- | --- |
| 内容为王 | 视频画面永远是视觉中心；UI 是服务层，不是主角 |
| 默认隐形 | 观看状态下所有控件自动隐藏，仅保留画面 |
| 内容驱动 | 背景、Accent 色可从媒体主色提取，但默认收敛：亮度 ≤10%，**禁止彩色发光阴影（colored glow）** |
| 玻璃层级 | **仅浮层**使用 Glass 材质；页面背景、列表项、磁贴等页面内元素一律哑光实色 |
| 动静有度 | 动画只服务于状态反馈，时长严格受限（120–400ms） |
| 深浅两套体验 | 普通用户只见 7 个核心控件；高级用户可进入完整控制台 |

## 2. 设计令牌（Design Tokens）

### 2.1 颜色

```text
--bg-base:        #0A0A0A   /* 应用底色 */
--bg-elevated:    #141414   /* 卡片/面板底 */
--surface-1:      #161616   /* 页面内哑光卡片/磁贴 */
--surface-2:      #1C1C1C   /* 页面内哑光控件（搜索框等） */
--surface-hover:  #232323
--hairline:       rgba(255,255,255,.06)  /* 分隔线 */
--text-primary:   #FFFFFF
--text-secondary: #AAAAAA
--text-muted:     #707070
--accent:         #4C8DFF   /* 仅用于进度已播段等极小面积强调；主交互色为白色系 */
--danger:         #E5484D
--warning:        #F5A524
--success:        #46A758
```

**禁令（v1.1 新增）：**
- 禁止彩色发光阴影（如 `box-shadow: 0 0 Npx <accent>`），阴影只用中性黑。
- 禁止锥形/多色渐变 Logo 与装饰；品牌标识使用纯文字 wordmark。
- 页面内元素禁止使用 Glass；Glass 仅用于浮层（播放控制层、气泡、模态）。
- 元数据规格（4K/HDR10/HEVC…）用纯文本 `·` 分隔，禁止堆砌胶囊标签。

Glass 材质分级：

| 层级 | 背景 | Blur | 边框 | 用途 |
| --- | --- | --- | --- | --- |
| Glass-1 | rgba(20,20,20,0.45) | 20px | rgba(255,255,255,0.08) | 播放控制栏 |
| Glass-2 | rgba(16,16,16,0.60) | 28px | rgba(255,255,255,0.10) | 控制台面板、设置浮层 |
| Glass-3 | rgba(12,12,12,0.75) | 40px | rgba(255,255,255,0.12) | 模态、错误卡片 |

降级策略：系统关闭透明效果或 GPU 性能不足时，Blur 降为 0，alpha 提升 +0.15，保证可读性。

### 2.2 字体与排版

```text
中文:  Microsoft YaHei UI / 等线
西文:  Segoe UI Variable
数字/时间码: Segoe UI Variable Text（启用 tabular-nums）
等宽(日志/HUD): Cascadia Mono
```

| 样式 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Display | 34 | 600 | 1.2 | 空闲页标题、欢迎语 |
| H1 | 24 | 600 | 1.3 | 页面标题 |
| H2 | 18 | 600 | 1.4 | 面板标题 |
| Body | 14 | 400 | 1.5 | 正文、列表 |
| Caption | 12 | 400 | 1.4 | 辅助信息 |
| Timecode | 13 | 500 | 1 | 播放时间（等宽数字） |

高 DPI：全部字号、间距使用逻辑像素，100%–300% 缩放下禁止位图拉伸；图标全部 SVG。

### 2.3 间距与圆角

```text
间距基数: 4px  → 4 / 8 / 12 / 16 / 24 / 32 / 48
圆角: 控件 8px · 卡片 12px · 浮层 16px · 全圆按钮 999px
最小触控区域: 40 × 40px
控制栏高度: 96px（含进度条区）
```

### 2.4 动效令牌

```text
--dur-instant: 120ms   /* hover、按下反馈 */
--dur-fast:    180ms   /* 控件显隐 */
--dur-normal:  240ms   /* 面板展开 */
--dur-slow:    400ms   /* 页面切换、全屏过渡 */
缓动: cubic-bezier(0.2, 0, 0, 1)（出场）/ cubic-bezier(0.4, 0, 1, 1)（退场）
```

规则：
- 播放中一切循环动画降速/降透明度 80%；暂停即静止。
- 系统开启“减少动画”时，全部动画替换为淡入淡出 ≤120ms。

### 2.5 主题系统（v1.2 新增）

明暗双主题，全部颜色经令牌切换（`<html data-theme="dark|light">`），禁止硬编码色值。

| 令牌 | 暗色（默认） | 浅色 |
| --- | --- | --- |
| `--bg-base` | `#0A0A0A` | `#F6F5F3` |
| `--surface-1/2/hover` | `#161616` / `#1C1C1C` / `#232323` | `#FFFFFF` / `#ECEAE7` / `#F0EFEC` |
| `--text-primary/secondary/muted` | `#FFF` / `#AAA` / `#707070` | `#1A1A1A` / `#5A5A5A` / `#8F8F8F` |
| `--hairline` | 白 6% | 黑 8% |
| `--glass-1/2/3` | 深玻璃 | 白玻璃（55%/65%/82%） |
| `--accent` | `#4C8DFF` | `#3B76E1` |
| `--btn-primary` | 白底黑字 | 黑底白字（反色式主按钮） |
| `--ambient-1/2` | 冷光 16% / 暖光 10% | 冷光 13% / 暖光 11% |

规则：
- 默认跟随系统（`prefers-color-scheme`），用户手动切换后持久化（本地存储），手动优先于系统。
- **播放页控件跟随主题**（v1.3 修订，原为恒暗）：控制层/抽屉/菜单等 UI 铬件使用 `--ov-*` 双套令牌随主题切换；视频画面本身不受主题影响。
- 主题切换过渡 ≤240ms，仅 `background-color` / `color` / `border-color`，禁止布局抖动。

### 2.6 环境光背景（v1.2 新增，Mineradio 式设计哲学；v1.3 补充粒子与镜头原则）

页面背景不是纯色，而是"舞台环境光"：

- **结构**：底色 + 双色柔光场（大面积 radial-gradient，inset 外扩避免边缘色块）+ 粒子尘光层 + 胶片颗粒（≤3%）。
- **柔光场**：一冷一暖两组低饱和色光，alpha 10%–16%，最终可从当前内容主色提取（M0 用固定值占位）。
- **粒子尘光**（v1.3）：细尘/粗尘两层圆点（box-shadow 分布），opacity ≤16%，46s/64s 异速缓慢浮动，模拟舞台空气中的微尘光点；`prefers-reduced-motion` 静止。
- **镜头语言**（v1.3）：背景的 32s 漂移即"缓慢运镜"；内容封面/海报的 hover/入场允许 1.02–1.05 倍的 Ken Burns 式推近。禁止快速、循环、闪切式运动。
- **动效**：32s 缓慢漂移（translate ≤3% + scale ≤1.05），`prefers-reduced-motion` 时静止；播放中按 §2.4 规则降速。
- **红线**：仍是背景不是主角——禁止高饱和、高对比、快速循环动画，不触犯 §2.1 发光禁令（柔光场与尘光是面光/点尘，不是彩色描边发光）。

## 3. 页面规范

### 3.1 首页（影音空间）

**结构：**

```text
┌────────────────────────────────────────────────┐
│ 顶栏: Logo · 全局搜索 · DLNA状态徽标 · 设置    │  56px, Glass-1
├────────────────────────────────────────────────┤
│ Hero 区: 继续播放卡片(大) + 背景主色渐变光晕    │
├────────────────────────────────────────────────┤
│ 快捷入口: 本地媒体 / 网络媒体 / DLNA / NAS     │  4 张磁贴
├────────────────────────────────────────────────┤
│ 最近播放: 横向海报列表(封面+进度条)             │
└────────────────────────────────────────────────┘
```

**规范：**
- 背景：环境光舞台（§2.6）——底色 + 双色柔光场 + 颗粒 ≤3%；内容主色提取为可选项。
- “继续播放”卡片：16:9 封面，右下角叠加剩余进度条（3px，Accent 色），hover 时封面轻微放大 1.03 倍并显示 ▶。
- 空态：Display 字号“欢迎回来”+ 引导操作（打开文件 / 添加媒体目录 / 等待投屏）。
- 禁止出现资源管理器式表格视图作为默认首页。

### 3.2 播放界面

**默认状态：** 仅视频画面。光标静止 3 秒或离开窗口后，控制层以 180ms 淡出，光标隐藏。

**控制层（鼠标移至底部 25% 区域触发）：**

```text
┌──────────────────────────────────────────────┐
│ 章节标记点 · 进度条(拖拽显示缩略图+时间气泡)  │
│ ◀  ▶  ▶|  ⏪10s  10s⏩   01:25:32 / 02:03:11 │
│ 🔊──────  字幕  音轨  画质  HDR  ⚙  ⛶       │
└──────────────────────────────────────────────┘
Glass-1, 圆角 16px, 距屏幕边缘 24px
```

- 进度条：静止高度 4px，hover 8px；缓冲段 30% 白，已播段 Accent 色。
- 缩略图气泡：160×90，下方时间码，来自预生成缓存（见引擎文档 §缩略图）。
- 顶部信息条（鼠标移至顶部触发）：文件名、视频规格摘要（`HEVC · 4K · HDR10 · 23.976`）、DLNA 投放来源（投屏时）。
- 加载态：中央呼吸圆环（Accent 色）；缓冲态：环形百分比；错误态：Glass-3 错误卡片（见 §6）。

### 3.3 播放控制台（五层）

从控制栏 ⚙ 或快捷键进入，右侧抽屉式浮层（宽 360px，Glass-2），五个分页：

1. **基础** — 播放速度（0.25–4x）、A-B 循环、画面比例、旋转、翻转
2. **视频** — 视频轨、HDR 模式、色彩模式、缩放算法、去隔行
3. **音频** — 音轨、声道、增益、音频延迟（±ms 步进 10）、输出设备、独占模式
4. **字幕** — 字幕轨、外部字幕载入、字号/颜色/描边/位置、字幕延迟、双语模式
5. **高级** — 解码器、渲染器、Shader、缓存、帧同步（默认折叠，需开启“高级设置”）

普通模式每个分页只显示 ≤8 个选项；其余收进“高级”。

### 3.4 设置页

左侧导航（宽 200px）+ 右侧内容区。分组：播放 / 视频 / 音频 / 字幕 / 网络 / DLNA / UI / 高级。右上角“高级设置”开关，开启后注入专家级选项并标注 ⚠。

所有设置项遵循：**label 左对齐、控件右对齐、当前值实时预览（如 HDR 调整直接作用于画面）**。

### 3.5 DLNA 投屏界面

- 接收中投屏时：左上角常驻 `CASTING · 设备名` 徽标（Glass-1 胶囊，48px 高）。
- 控制栏简化为：播放/暂停、进度、音量、字幕、音轨、停止投屏。
- 待机态（DLNA 空闲）：背景为低亮度动态极光渐变，中央显示设备名与“等待投屏…”。
- 投屏结束：最后画面定格 2 秒 → 400ms 淡出 → 回到待机态。

### 3.6 媒体库（P1）

海报墙网格：海报 2:3，间距 16px，5–8 列自适应。顶部筛选（电影/剧集/动漫/纪录片）。悬停显示规格标签（`4K` `HDR10` `ASS`）。默认仅本地元数据，联网刮削需用户显式开启。

## 6. 错误与空态规范

播放失败卡片必须包含四段式信息：

```text
标题: 无法播放该文件
原因: HEVC 解码初始化失败（0x8007000E）
已尝试: D3D11VA ✗ → Hardware Copy ✗ → Software ✗
操作: [切换软件解码] [查看详情] [导出日志] [重试]
```

禁止只显示“播放失败”。所有错误文案用用户语言描述，技术细节折叠进“查看详情”。

## 7. 交互规范摘要

- 快捷键：遵循 PRD §51 默认表，全部可在设置中重绑定，冲突时红色提示。
- 鼠标：单击播放/暂停、双击全屏、滚轮音量、Shift+滚轮 Seek、中键播放/暂停、右键上下文菜单。
- 触控：Tap=播放/暂停，Double Tap=全屏，左右 Swipe=±10s，上下 Swipe(右侧)=音量，Pinch=缩放（预留）。
- 自动隐藏：控制层出现期间若用户持续操作则不隐藏；停止操作 3 秒后隐藏；播放暂停时控制层常驻。
- 多显示器：全屏目标显示器可选；窗口跨屏拖动时按目标屏 DPI/HDR 能力实时重建渲染链。
- 可访问性：全键盘可达（Tab 顺序 = 视觉顺序）、焦点环 2px Accent、高对比主题、屏幕阅读器朗读所有控件 label。

## 8. 状态视觉映射

| 播放状态 | 视觉反馈 |
| --- | --- |
| Playing | 控制层隐藏，背景微动态 |

## 9. 交付与实施约束

- UI 技术栈：React + TypeScript + WebView2（视频渲染层为原生 D3D11 表面，禁止用 `<video>` 承担主播放）。
- UI 帧率目标 60 FPS（高端 120），播放 4K HDR 时动画不得掉帧；所有动画走合成器线程（transform/opacity），禁止触发布局抖动。
- 所有颜色对比度 ≥ WCAG AA（4.5:1），Glass 层下文字加 1px 深色描边保底。
- 状态单向流动：`Media Engine → State Store → UI`，UI 不直接持有播放状态副本。

## 10. 变更记录

### v1.1（2026-08-12）— 去"AI 味"整改

M0 视觉原型评审反馈：原型呈现典型 AI 生成感。整改方向：克制影院风（参考 Infuse / Apple TV）。

- 新增禁令：彩色发光阴影、锥形渐变 Logo、页面内元素滥用 Glass、胶囊标签堆砌（§2.1）
- Accent 收敛：主交互色改白色系，`--accent` 仅用于进度已播段等极小面积；删除 `--accent-soft`
- 新增令牌：`--surface-1/2/hover`、`--hairline`（页面内哑光材质）
- §3.1 首页背景：内容主色渐变 → 近纯黑 + 微弱压暗，颗粒 5% → ≤3%
- §4 Slider：滑块去 Accent 光晕，14px → 12px 纯白
- §5 Cinema 模式：默认近纯黑；彩色光晕归入 Aurora 可选模式
- 元数据规格统一为纯文本 `·` 分隔（首页 Hero、播放页顶部信息条）

### v1.2（2026-08-12）— 双主题 + 环境光背景

用户反馈：背景单调、缺浅色/暗色切换；明确 UI 仿照 Mineradio 的设计哲学。

- 新增 §2.5 主题系统：明/暗双套令牌，跟随系统 + 手动切换持久化，播放页恒暗
- 新增 §2.6 环境光背景：Mineradio 式柔光场（双色低饱和面光 + 32s 缓慢漂移 + 颗粒），替代纯色背景
- 新增令牌：`--btn-primary-bg/fg`（反色主按钮）、`--ambient-1/2`、`--stage-top`、`--grain-opacity`
- 原型：共享 `.ambient-stage`、`.theme-toggle` 组件入 `aurora.css`

### v1.3（2026-08-12）— 沉浸式视觉定位 + 浅色主题全覆盖

用户明确产品定位：**以电影镜头、粒子视觉和舞台为核心的沉浸式播放器**。

- §2.6 补充：粒子尘光层、镜头语言（缓慢运镜/Ken Burns 推近）原则
- §2.5 修订：播放页控件跟随主题（原"恒暗"作废），新增 `--ov-*` 播放覆盖层双套令牌；视频画面本身不受主题影响
- 新增 `--cv-*` 封面占位令牌：浅色主题下封面/Hero 为亮调渐变，不再是黑盒子
- 播放窗：顶部 14px 隐形拖拽条（透明窗无标题栏）；视频就绪前控制层保持黑场，不透出下层窗口
