## 黑屏事故与架构修正（2026-08-12，用户上报：有声无画）

**根因**：`--wid` 嵌入 Electron 主窗口 HWND 时，Chromium 的 DirectComposition 合成层绘制在 mpv 子窗口**之上**——页面纯黑即盖住视频。与 VO 无关（gpu-next/direct3d 均黑），与叠加窗无关（无叠加也黑）。mpv 日志 VO 初始化成功，具迷惑性。

**修正**：放弃"视频窗 + 独立叠加窗"双窗模型，改**单窗透明方案**：
- 播放窗 = `transparent: true` 的 Electron 窗，直接加载 React #/player 控制层
- mpv `--wid` 子窗口在下层透过透明 DComp 层显示（Electron+mpv 社区标准做法）
- 控制层底色 `rgba(0,0,0,.004)`：肉眼不可见，避免纯透明像素鼠标穿透
- 架构简化：删除 overlayWin、边界同步、鼠标穿透 IPC

**无头验证法**（后续回归可用）：`scripts/screen-probe.ps1` 置前窗口→截图→中央区平均亮度（黑=0.0，正常=127.0）；mpv 日志在 `userData/mpv.log`（`--log-file` 常驻，支撑规范 §6 导出日志）。
